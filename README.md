## 📌 Overview

Welcome to my **Machine Learning Projects Portfolio**.

This repository contains multiple end-to-end machine learning projects covering **classification, Natural Language Processing (NLP), fraud detection, text preprocessing, feature engineering, model evaluation, and deployment-ready model serialization**.

Each project follows a complete machine learning workflow including:

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Cleaning & Preprocessing
- ⚙️ Feature Engineering
- 🤖 Model Training
- 📈 Performance Evaluation
- 💾 Model Saving using Joblib
- 📄 Detailed Project Documentation

# 📂 Projects

## 💳 Credit Card Fraud Detection

**Objective**

Build a machine learning model to identify fraudulent credit card transactions from highly imbalanced transaction data.

### Highlights

- Feature Engineering
- Log Transformation
- StandardScaler
- SMOTE
- Logistic Regression
- Random Forest
- XGBoost
- ROC-AUC Evaluation

**Dataset**

https://www.kaggle.com/datasets/kartik2112/fraud-detection

📁 Folder:

```
Credit-Card-Fraud-Detection/
```

## 📩 SMS Spam Classification

**Objective**

Automatically classify SMS messages as Spam or Ham using Natural Language Processing techniques.

### Highlights

- Lemmatization

- TF-IDF
- Multinomial Naive Bayes
- LinearSVC
